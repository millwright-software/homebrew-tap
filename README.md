# Millwright Software Homebrew tap

```sh
brew install --cask millwright-software/tap/quill        # dictation and meetings, macOS menu-bar app
brew install millwright-software/tap/agent-desk          # terminal session manager for AI coding agents
```

Upgrade with `brew upgrade`. Sources: [quill](https://github.com/millwright-software/quill), [agent-desk](https://github.com/millwright-software/agent-desk).
